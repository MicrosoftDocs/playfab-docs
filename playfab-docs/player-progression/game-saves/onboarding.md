# Onboarding to Game Saves preview

Game Saves is in a limited public preview so we can make sure the preview is a good fit for your upcoming title and so we can provide access to a preview GDK. To request access, select your title in [PlayFab Game Manager](https://developer.playfab.com/), navigate to Progression | Game Saves (Preview) and join the waitlist.

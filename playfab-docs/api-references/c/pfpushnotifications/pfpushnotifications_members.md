# Services C API overview - PFPushNotifications.h

  
## Functions  

| Function | Description |  
| --- | --- |  
| [PFPushNotificationsServerSendPushNotificationAsync](functions/pfpushnotificationsserversendpushnotificationasync.md) | Sends an iOS/Android Push Notification to a specific user, if that user's device has been configured for Push Notifications in PlayFab. If a user has linked both Android and iOS devices, both will be notified. |  
| [PFPushNotificationsServerSendPushNotificationFromTemplateAsync](functions/pfpushnotificationsserversendpushnotificationfromtemplateasync.md) | Sends an iOS/Android Push Notification template to a specific user, if that user's device has been configured for Push Notifications in PlayFab. If a user has linked both Android and iOS devices, both will be notified. |
